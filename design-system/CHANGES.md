# Mossbell／墨贝，v1.2 改动说明

- **列表改为编辑式目录。** 一行一个项目，桌面三列 96 px / 说明 / 280 px，列间距 32 px、行上下 48 px、暖灰细线分隔；手机图标与标题并排，其余满宽。
- **新增四类组件。** 项目图标、分类头、成果数字、流程步骤纳入系统；图标共享 16 / 12 px 圆角变量，暖灰底块统一 4 px。
- **统一字号、行高与间距。** 字号只用七级，删除旧 24 px 项目标题与流动字号；补充 1.6 引导行高，所有作品集样式通过同一份 token 引用。
- **统一交互与红色。** 首页入口与 GitHub 常驻下划线，详情首外链为主按钮，其余为次按钮；手机「代表项目」为辅助灰；焦点偏移 4 px。
- **对齐详情组件。** 关键判断为 24 px 内边距、3 px 红线、无圆角；证据块顶部细线、无底色与圆角，数字固定 28 px；列表项间距 16 px。
- **更新五个项目示例。** DramaPilot、《送灯》AI 动画短片、公积金政策问答、MiroFish 消歧 Agent、YouTube 评论话题分析按三类分组，沿用页面现有颜色、图形、文案与地址。MiroFish 标记 warm 并改用暖黑图标线条。
- **保留部署方式。** 作品集仍为一个 HTML，内嵌与 tokens.css 完全相同的根变量；设计系统的独立目录预览复用同一示例。未发布线上变更。

验收结果见作品集相邻的 `acceptance-v1.2/`；1280 / 375 px 首页与公积金详情页四张截图已生成并逐张目视检查。额外宽度及完整浏览器检查的最终日志尚待核对，详见报告。

# Mossbell／墨贝，v1.1 改动说明

- **新增项目卡片与列表页。** 用四个真实项目试排，DramaPilot 为头牌大卡，其余项目宽屏双列、窄屏单列。固定封面、价值、角色与时间、标签、入口的阅读顺序，使招聘方先看项目，再选择复盘或 Demo。
- **分开外壳色与项目色。** 每张卡片通过 `--project-accent` 设置局部示意色，只用于封面和一个小圆点；红橙项目的小圆点改用暖黑。避免 Demo 的配色扩散到作品集的文字、按钮或背景。
- **精简状态并分开报错语义。** 按钮只保留默认、悬停、焦点、按下、不可用五种状态；必要报错使用暖黑、叹号与文字。品牌红保留给交互和每页最多一处关键判断。
- **改用本地字体。** 删除 Google Fonts、字体预连接和在线字体依赖，按苹方、微软雅黑、本地 Noto Sans SC 等本机字体回退。首屏直接使用可用字体，避免远程字体替换造成跳闪。
- **统一署名与签名。** 全站使用 Mossbell／墨贝，以及 4 px 高、比例为 3∶1∶4 的暖黑—红—暖灰页眉横线。列表、封面与复盘页延续同一结构，不叠加超大项目序号。
- **同步规范与变量。** 五个文件统一到 v1.1，保留原四种基础配色、结论与证据模块、对比度底线及面试投屏规范。缺失的角色、时间、数据与网址均明确写「待补充」。

## 预览与补充信息

打开 `index.html` 查看完整规范，在页面中点击「独立查看列表页」即可进入同一份内容的独立列表预览。也可在浏览器访问 `index.html?view=portfolio`。

项目的具体 Demo、GitHub、详情地址尚未提供，所以真实项目卡片没有显示空链接按钮；在 `.project-actions` 上填入对应的 `data-demo-url`、`data-github-url`、`data-details-url` 后才会显示入口。封面色仅用于试排，不代表项目的实际品牌色。
